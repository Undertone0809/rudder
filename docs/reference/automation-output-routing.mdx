Automation output routing decides where people inspect the result.

## Choose issue output

Use issue output when the result needs:

- assignment
- status tracking
- review
- artifacts or files
- follow-up work
- durable close-out evidence

Issue output enters the normal issue lifecycle. This is the safer choice for work that affects decisions, customers, releases, or team commitments.

## Choose chat output

Use chat output when people should receive and continue the result through a conversation rather than a structured issue lifecycle.

Good examples:

- iterative reports that invite follow-up questions
- status checks that operators want to continue in context
- informational replies delivered as a conversation
- analysis that benefits from conversational refinement

Chat output keeps the audit trail on the automation run and the chat transcript.

## If unsure

Choose issue output for explicit assignment, status, or lifecycle management. Choose chat output for conversation-driven delivery and follow-up. Importance and run length alone do not decide the mode.
