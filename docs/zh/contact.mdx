## 缺陷报告

请提供能说明问题的最小复现：

- Rudder 版本或提交版本
- 操作系统和安装命令
- 预期行为与实际行为
- 相关日志、截图或终端输出

公开发布前，应删除 API 密钥、凭据、客户数据、私有仓库内容和其他敏感信息。

## 功能建议

说明你想完成什么、现在怎样做、Rudder 在哪里造成阻碍，以及成功结果应该是什么
样子。一个具体例子比一组界面控件更有帮助。
