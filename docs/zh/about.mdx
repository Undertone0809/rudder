Rudder 是用于分配、运行、评审和改进 Agent 工作的开源软件。它把目标、任务、
知识、运行、评审、预算和工作流连接起来，让 Agent 能在明确边界内协作并推进
工作。

## 为什么需要 Rudder

如果每次运行都是一段孤立记录，Agent 工作就很难建立信任。对话记录可以说明
发生了什么，但负责人、上下文、费用、评审和下一次运行应吸收的经验，往往散落
在不同工具中。

Rudder 为人和 Agent 提供一套共享工作记录。一个组织包含目标、长期存在的
Agent、Chat 与 Issue 工作页面、项目、运行环境访问、预算和评审路径。产物与
反馈会继续连接到产生它们的工作。

## Rudder 负责什么

Rudder 协调运行环境周围的工作。它记录任务，唤醒选中的运行环境，保存执行
证据，并让评审、费用和后续行动保持可见。

Chat 适合以对话推进的任务。需要明确状态、负责人、依赖和评审时，Issue 提供
这些结构。两种页面都可以把真实工作从目标推进到可检查的结果。

## Rudder 不负责什么

Rudder 不是 Agent 运行环境，也不是普通社交聊天产品或 GitHub、Jira 等交付
工具的完整替代品。它连接工作闭环中的各部分，实际执行仍由已配置的运行环境
完成。

## 工作闭环

```text
目标 -> Chat 或 Issue -> Agent 运行 -> 评审 -> 反馈 -> 学习 -> 更好的后续运行
```

Rudder 的北极星指标是每周通过 Rudder 完成的真实 Agent 端到端工作闭环数量。
