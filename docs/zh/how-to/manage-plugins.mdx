<a id="completed-state" />

## 完成后的状态

完成本页后，一个可信 CRM 插件已经从受支持来源安装，声明的能力和配置经过检查，工作进程保持健康，而且一次测试同步留下了插件自己的日志和状态。

<a id="prerequisites" />

## 开始前

你需要访问 `Plugin Manager`，准备软件包或来源、配置与外部服务要求，以及回滚或卸载节点。插件会运行已经安装的工作进程和前端代码。能力检查会限制宿主桥接操作，但它不是运行不可信软件包的安全沙箱。

<a id="case-backed-steps" />

## 安装 CRM 插件

1. 打开 **Plugin Manager**，选择 CRM 插件受支持的软件包或来源。
2. 检查插件身份、版本、工作进程和界面软件包、配置字段、外部服务、工具、事件、后台任务、webhook 和申请的宿主能力。
3. 确认每个工具名称都带插件命名空间，而且插件没有声称拥有核心 Issue、审批、预算、身份验证或签出规则。
4. 通过插件设置填写必要配置，不要把凭据写进软件包或日志。
5. 安装并启用插件。使用项目面板前，先检查工作进程健康状态和启动日志。
6. 触发一次账户同步，检查插件任务记录、日志、状态和任何关联的 Rudder 工作。
7. 更新前比较版本、能力、配置变化和迁移说明。卸载前先停止依赖它的工作。

<a id="success-signal" />

## 成功信号

Plugin Manager 显示预期版本和健康工作进程。测试同步明确归属于该插件，状态、日志和插件数据都可以检查。核心 Issue、运行、审批和预算仍沿用 Rudder 原有页面和规则。

<a id="recovery" />

## 恢复

启用失败时，让插件保持关闭，检查清单校验、配置、工作进程健康和日志。先修复明确指出的软件包或能力问题，再重试。桥接操作被禁止时，应当失败并留在日志中，不能改走内部路由绕过限制。

更新破坏插件时，停止它的任务和 webhook。如果安装来源支持恢复，就回到上一个经过评审的软件包；否则通过 Plugin Manager 卸载。卸载应停止插件工作进程并整理插件自有状态，不能删除 Rudder 核心记录。
