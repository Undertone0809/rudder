用 plugins 在 Rudder 核心协作层之外增加能力。

## 安装前

先检查 plugin 声明了什么：

- capabilities
- jobs
- webhooks
- UI slots
- configuration fields
- 需要的 external services

只安装你信任来源的 plugins。Plugin 可以增加 integration 能力，但不应该替代 Rudder 对 organizations、issues、approvals、budgets 或 runs 的核心规则。

## 安装和启用

1. 打开 plugin manager。
2. 选择 plugin package 或 source。
3. 检查 declared capabilities。
4. 填写必要 configuration。
5. 安装 plugin。
6. 配置完成后 activate。

启用后，先检查 worker health 和 logs，再把它用于真实工作。

## 检查 plugin 行为

当 plugin 触发了变化，检查：

- worker status
- recent jobs
- webhook delivery
- logs
- output links
- plugin-owned UI surfaces

如果 plugin 通过 webhook 或 scheduled job 启动工作，确认结果仍然能在 Rudder 里看到。

## 更新或移除

更新前检查 plugin 是否改变 capabilities 或 configuration。移除前检查 active jobs、webhooks 或 UI surfaces 是否依赖它。

移除 plugin 不应该删除核心 Rudder records，例如 issues、approvals、budgets 或 run history。
