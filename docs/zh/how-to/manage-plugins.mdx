插件会运行安装到电脑上的代码。只使用你信任的软件包，并在启用前看清它申请了
什么能力。

<a id="completed-state" />

## 这篇指南会做什么

安装一个插件，检查它的能力与设置，确认后台进程正常，并测试一次真实操作。

<a id="prerequisites" />

## 开始前

准备插件来源、设置说明、需要连接的外部服务账号，以及已知可用的旧版本或卸载
路径。不要把凭据写进软件包或日志。

<a id="case-backed-steps" />

## 安装并测试

1. 打开**插件管理**，选择受支持的软件包或来源。
2. 检查发布者、版本、后台和界面代码、外部服务、申请的能力、工具、任务与
   Webhook。
3. 填写必要设置，凭据只保存到专门的密钥字段。
4. 安装并启用插件。
5. 使用插件界面前，先确认后台进程和启动日志正常。
6. 触发一次小型测试操作。
7. 打开插件任务、日志和状态，确认实际发生了什么。
8. 更新前，检查版本变化、新增能力、配置变化和迁移说明。

<a id="success-signal" />

## 检查结果

插件管理应该显示预期版本和正常的后台进程。测试操作应该记录在这个插件名下，
并有可以阅读的状态和日志。

<a id="recovery" />

## 启用或更新失败怎么办

- 设置或软件包有问题时，让插件保持未启用。
- 阅读提示中的清单、能力、后台进程或连接错误。
- 卸载前先停止依赖它的任务和 Webhook。
- 安装来源支持时，回到上一个已经检查的版本；否则通过插件管理卸载。

卸载插件只应删除它自己的后台进程和状态，不能删除 Rudder 核心 Issue、运行、
评审、审批或预算。
