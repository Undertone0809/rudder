<a id="definition" />

## 浏览器有两种用法

**你可以在 Rudder 旁边浏览网页。**链接可以在侧边面板打开，也可以把同一个实时
标签页移到 Messenger 主工作区，或交给系统浏览器。移动时会保留历史、表单内容、
滚动位置和缩放。

**Agent 可以使用受控标签页。**开启 Agent 浏览器权限后，受支持的本地运行可以
导航、阅读、点击、输入和截图。

<a id="case" />

## 例子：检查已经发布的页面

Agent 写发布说明前，在自己的标签页中打开公开安装页面，确认当前命令并截图。
它不能读取你正在使用的标签页，也不能读取其他运行拥有的标签页。

<a id="when-useful" />

## 同一个本地实例共享网站登录

操作人员浏览器会为当前系统用户和本地 Rudder 实例保留一个网站配置。在一个
组织里登录网站后，切换到另一个组织时，这个网站仍可能保持登录。

这样日常浏览更方便，也意味着应把浏览器看成一个共享的本地身份。清除浏览数据会
影响这个本地实例里的所有组织。

<a id="operating-boundaries" />

## Agent 标签页彼此隔离

Agent 只能使用 Rudder 为当前工作打开的浏览器标签页。它拿不到原始 Cookie、
保存的密码、任意页面脚本，也看不到其他运行的标签页。

把自己的链接改用系统浏览器，不会关闭 Agent 浏览器。关闭 Agent 访问会关掉
受控标签页，但会保留你的标签页和网站数据。

Agent 浏览器适用于 Desktop 本地可信模式下受支持的 Codex、Claude、OpenCode
和 Pi 本地运行工具。在 macOS 上，经确认后可以从指定 Chrome、Edge 或 Brave
配置导入受支持的 Cookie。

参见[权限与平台](/zh/reference/permissions-and-platforms)。
