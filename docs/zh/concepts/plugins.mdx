<a id="definition" />

## 插件可以增加什么

插件是由 Rudder 主机安装的可选软件包。根据具体插件，它可以增加：

- Agent 可以使用的工具
- 与其他服务的连接
- 后台任务和 Webhook
- 项目面板或其他界面区域
- 插件自己的设置和状态

Rudder 会显示插件版本、配置、运行状态、日志、任务、Webhook 和它申请的主机
能力。

<a id="case" />

## 例子：连接 CRM

一个 CRM 插件在项目中增加客户面板，并按日程同步账号。同步失败时，可以在这个
插件下找到任务和日志。插件可以把客户连接到 Rudder 工作，但不能自己创造新的
Issue 状态，也不能绕过正常审批。

<a id="when-useful" />

## 用插件扩展可选能力

并非每位 Rudder 用户都需要的集成和专用工具，适合做成插件。目标、Chat、Issue、
运行、评审、预算和工作区负责组织核心工作，因此仍然属于内置功能。

<a id="operating-boundaries" />

## 只安装你信任的代码

插件包含会随安装运行的后台或界面代码。能力检查可以限制插件怎样连接 Rudder，
但不会把不可信软件包变成安全沙箱。

启用前，检查来源、发布者、版本、申请的能力、外部服务、配置和更新说明。卸载
插件会停止它的后台进程并处理自身状态，不应该删除核心 Issue、运行、审批或预算。

安装和测试步骤见[管理插件](/zh/how-to/manage-plugins)。
