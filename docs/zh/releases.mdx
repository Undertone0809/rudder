## v0.7.16

[GitHub Release](https://github.com/Undertone0809/rudder/releases/tag/v0.7.16)

这个版本让 Agent 更容易委派和恢复工作，并为运行调试、长时间运行、Chat、Desktop 和本地化体验带来更可靠的支持。

### 新功能

- 增加受治理的 Delegation Run：Agent 可以通过 `rudder runs create` 或 MCP，为自己或同一组织中的另一个 Agent 创建独立运行，并保留来源关联、支持幂等重放，还可以在 Agent 详情中按 Delegation 筛选。
- 为失败的 Agent Run 增加 Debug Chat。在 Run Detail 中，可以把经过限制和脱敏的诊断信息发送给 Agent，并在侧面板中继续处理；目标 Agent 不可用时可以切换后重试，也可以在打开 GitHub Issue 前先检查诊断内容。
- 为 Hermes Gateway 增加按运行同步技能。为 Agent 选择组织技能后，Rudder 会把已选技能同步到每次新运行中，不会修改 Hermes 的技能目录。

### 改进

- Agent Run 默认不会仅因运行时间过长或长时间无活动而超时。连续 24 小时没有记录到活动时，Rudder 会发出提醒，但保留运行中的状态。
- 让 Chat 发送具备可重试性和持久幂等性，避免重复消息，并在发送或流式响应失败时保留草稿；消息编辑现在仅允许修改最新一条用户消息。
- 在 Agent 详情的所有视图中增加查找支持，提供匹配高亮和键盘导航。
- 改进 Desktop 本地应用恢复：重启后保留有界运行日志，便于继续诊断。
- 为不可逆的删除操作增加确认，并改善 Issue、工作区和状态界面的简体中文用词。

### 问题修复

- 修复 Run Detail 中 Transcript 批注和流式活动在运行更新时消失的问题。
- 修复 Markdown 实时预览中的无序列表项目符号和流式更新时的文本选中；网站图标的临时加载失败现在可以干净重试。
- 修复原生 CLI/MCP 对 Unicode 字符串长度的计算不一致问题，让非 ASCII 输入得到一致处理。
- 修复有界工具失败和等待网络的恢复路径，避免 Run 或 Debug Chat 停留在过时状态。
- 修复 macOS 透明窗口可能出现的渲染异常。

</Update>

## v0.7.15

[GitHub Release](https://github.com/Undertone0809/rudder/releases/tag/v0.7.15)

这个版本让 Rudder 更容易理解 Agent 的工具结果和运行记录，并为 Chat、Desktop 及跨平台安装提供更可靠的恢复体验。

### 新功能

- 为 40 个内置 Rudder MCP 工具增加语义结果卡片，覆盖 Goal、Issue、Project、审批和 Automation。卡片可链接到相关记录，显示摘要和结构化回执，长列表按需渐进加载，明确呈现最终结果，并隐藏 Webhook 密钥。
- 在 Run Detail 中为稳定的 Transcript 条目增加批注，并支持选中文本后将其作为反馈发送。
- 将命令详情重做为聚焦的 Shell 视图，支持复制命令输出，并移除 Task 和 Markdown 页签。

### 改进

- 改进 Chat 反馈恢复：对话缺失时仍保留草稿和批注，Project 上下文加载失败会重试，并防止同一发送操作重复提交。
- 让失败的 Chat 回复更容易处理：现在聚焦于“重试”和“打开运行”，不再显示过时的回复内容或操作。
- Chat 草稿不再需要等待运行时上下文准备完成后才可用。
- 改进 Markdown 渲染和编辑中链接、图片及文本选中的稳定性，并让窄窗口下的 Issue 创建控件保持可用。
- 改进 Desktop 账户信息连续性：头像在重启后仍会保留，图片无法加载时回退为姓名首字母。

### 问题修复

- 修复 Windows CLI 安装和运行时安装中的 npm 调用问题。
- 修复 Desktop 渲染器重新加载后版本说明消失的问题；在用户确认前，版本说明会继续可用。

</Update>

- 修复网络恢复无法安全继续时的处理，现在会显示可重试的 Chat 错误。
- 修复被动后续运行丢失原始 Issue 上下文、负责人、评审者和时间信息的问题。
- 修复网站链接图标在链接变化后保留旧加载或错误状态的问题；图标失败时会可靠回退。
- 修复 Issue 卡片对昨天的记录不显示具体时间的问题。

</Update>

## v0.7.2

[GitHub Release](https://github.com/Undertone0809/rudder/releases/tag/v0.7.2)

这个版本提供更连续的 Agent 工作台、更清晰的 Goal 进展与验收流程，以及更丰富的运行证据查看能力。

**Beta 测试：** Goal 工作区及 Goal 对齐与验收流程目前仍处于 Beta 测试阶段，使用前请在 **Settings > Experimental** 中开启。

### 新功能

- 增加 Messenger 工作台，可在可排序的标签页中统一管理 Browser、Library、Automation、本地应用和已保存视图，并在 Side Panel 与主工作台之间保留实时界面。
- 增加 Goal 工作区，按下一步行动者或状态组织工作，包括 Agent 推进、需要你关注、等待外部结果、待验收和历史记录。
- 增加 Goal 对齐与契约流程，在开始工作前预览结果、成功标准、负责人、边界和第一步行动，并支持反馈、证据、变更审阅和结果验收。
- 增加运行产物检查，可在 Agent transcript 中查看文件变更、统一 diff、图片证据和本地文件预览。
- 增加 Hermes API Server Agent 运行环境。

### 改进

- 改进 Agent 运行环境配置，使推理控制、模型发现、回退顺序与所选模型能力保持一致，并刷新 OpenClaw Gateway 兼容性。
- 改进 Messenger 连续性，让 Side Chat 流、已保存视图和工作台实时界面在导航过程中保留上下文。
