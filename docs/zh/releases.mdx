## v0.7.4

[GitHub Release](https://github.com/Undertone0809/rudder/releases/tag/v0.7.4)

这个版本新增实验性 Computer Use 和 Plugin V1，为 Agent 提供更清晰的人工协助与恢复路径，并改善 Chat、Goal、运行记录和 Issue 时间线的连续性。

### 新功能

- 为受支持的 macOS Rudder Desktop 增加实验性 Computer Use。该功能默认关闭，并需要授予设备权限。
- 增加 Codex 兼容的 Plugin V1，可检查和安装由 Skill、MCP Server 与 Local App 组成的软件包。
- 增加统一 Requests 工作区，在 Issue 详情、Inbox 和 Messenger 中集中处理 Agent 求助与审批。
- 运行记录支持打开多个本地或生成的文件目标，同时保留当前运行上下文。

### 改进

- 改进 Goal 协作与验收，提供更清晰的工作状态、负责人和契约要求、进度、证据、变更提案与结果审阅。
- 改进 Chat 和 Messenger 的导航连续性，提供更清晰的运行时与模型选择，并简化移动端 Chat 导航。
- 改进 Markdown 编辑，支持直接编辑表格单元格，并提升图片粘贴、上传和预览的可靠性。
- 改进 Issue 时间线的渐进式展开和双向加载。
- 改进 Local App 的启动、停止和后台刷新行为。

### 问题修复

- 修复运行记录图片证据无法持久保存，以及本地文件预览无法保持上下文的问题。
- 修复流式回复期间 Chat 输入框闪烁，以及窄屏 Side Panel 的部分状态问题。
- 修复求助卡片和审批卡片显示与决策类型不匹配操作的问题。
- 修复加载 Issue 时间线历史时出现活动缺失或重复的问题。

</Update>

## v0.7.2

[GitHub Release](https://github.com/Undertone0809/rudder/releases/tag/v0.7.2)

这个版本提供更连续的 Agent 工作台、更清晰的 Goal 进展与验收流程，以及更丰富的运行证据查看能力。

**Beta 测试：** Goal 工作区及 Goal 对齐与验收流程目前仍处于 Beta 测试阶段，使用前请在 **Settings > Experimental** 中开启。

### 新功能

- 增加 Messenger 工作台，可在可排序的标签页中统一管理 Browser、Library、Automation、本地应用和已保存视图，并在 Side Panel 与主工作台之间保留实时界面。
- 增加 Goal 工作区，按下一步行动者或状态组织工作，包括 Agent 推进、需要你关注、等待外部结果、待验收和历史记录。
- 增加 Goal 对齐与契约流程，在开始工作前预览结果、成功标准、负责人、边界和第一步行动，并支持反馈、证据、变更审阅和结果验收。
- 增加运行产物检查，可在 Agent transcript 中查看文件变更、统一 diff、图片证据和本地文件预览。
- 增加 Hermes API Server Agent 运行环境。

### 改进

- 改进 Agent 运行环境配置，使推理控制、模型发现、回退顺序与所选模型能力保持一致，并刷新 OpenClaw Gateway 兼容性。
- 改进 Messenger 连续性，让 Side Chat 流、已保存视图和工作台实时界面在导航过程中保留上下文。
- 改进 Desktop 和本地工作区的启动与升级可靠性，增强打包服务兼容性和嵌入式 PostgreSQL 迁移处理。

### 问题修复

- 修复 Side Chat 在导航过程中丢失流身份，以及 Messenger 中过期 Issue 提醒仍然显示的问题。
- 修复窄屏下运行产物检查、过长内联标签和 Side Panel 源码滚动的问题。
- 修复编辑 Issue 时内联图片无法继续预览的问题，并修复 Chat 滚动和流式输入边界状态。
- 修复未明确调用 Rudder Browser 时仍可能触发 Browser 操作的问题。

</Update>

## v0.7.1

- 修复 Markdown 实时预览中的可见文本选择和区块操作，并保持运行批注编辑器清晰可读。
- 修复 Automation 模型菜单对齐问题，并让较早活动的时间显示更明确。
- 修复浏览器代理注册中断后 Browser 会话无法恢复的问题。

### 新功能

- 增加 Rudder Account 登录和设备会话管理，并支持原生邮箱验证、密码流程以及 Google 和 GitHub 登录。

- 增加面向记录的 Chat 运行反馈与批注，支持链接到 Agent 运行证据，并提供更清晰的进行中和已完成子 Agent 工作清单。
- 为 Library、Issue、Project、Goal、Automation 和文件审阅等支持的界面增加 CodeMirror Markdown 实时预览。
- 增加按范围隔离的 Smart Model 搜索回退，以及用于衡量完成工作周期的本地隐私分析记录。

### 改进

- 改进 Messenger 分组、已保存视图、Side Chat 连续性、滚动和活动投影，让高活跃工作区更容易扫描。
- 改进 Chat 与 Automation 的运行环境选择、Agent 身份、技能加载、本地运行环境兼容性，以及 heartbeat/run 投影。
- 改进 Desktop 启动、账号恢复、本地应用进程所有权、浏览器注册、更新检查、重启行为，以及 macOS、Windows 和 Linux 的打包验证。
- 改进文件审阅、Markdown 编辑、工作区导航、移动端 Messenger 入口、组织引导和账号/个人资料设置。

### 问题修复

- 修复账号 OAuth 与设备审批收敛、原生邮箱认证恢复、安全本地会话处理，以及在缺少预期会话时仍执行更新检查的问题。
- 修复历史 Chat 操作、Side Chat 用户消息可见性、响应批注范围处理、文件链接与预览、Markdown 光标移动，以及添加 Library 引用后的输入框状态。
- 修复本地应用就绪与清理竞争、运行时所有权检查、平台相关的打包启动行为、Issue 无实际修改时的活动时间，以及多项品牌和文件桥接边界问题。

</Update>
