Automation output routing 决定人在哪里检查结果。

## 选择 issue output

结果需要这些东西时，用 issue output：

- assignment
- status tracking
- review
- artifacts 或 files
- follow-up work
- durable close-out evidence

Issue output 会进入正常 issue lifecycle。影响 decisions、customers、releases 或 team commitments 的工作，通常应该用它。

## 选择 chat output

希望人通过对话接收结果并继续追问或调整时，用 chat output，而不是进入结构化 issue lifecycle。

适合的例子：

- 适合继续追问的周期报告
- 希望留在同一上下文里的状态检查
- 通过对话交付的信息回复
- 适合继续调整的分析

Chat output 把 audit trail 留在 automation run 和 chat transcript 上。

## 不确定时

需要明确 assignment、status 或 lifecycle 管理时，选 issue output；希望通过持续对话交付和跟进时，选 chat output。任务重要程度和运行时长本身不决定模式。
