<a id="definition" />

运行工具是执行一次 Agent 运行的程序或服务。Agent 负责长期职责，运行工具负责
执行，运行记录保存这次尝试。

<a id="states" />

## Agent 设置里的本地运行工具

| 选项 | 默认命令 |
| --- | --- |
| Codex | `codex` |
| Claude Code | `claude` |
| Cursor | `cursor-agent` |
| Gemini CLI | `gemini` |
| OpenCode | `opencode` |
| Pi | `pi` |

设置表单会分成：

- **本机已就绪：**Rudder 找到了默认命令。
- **需要设置：**没有找到命令。
- **其他运行工具：**无法通过本地命令判断是否就绪。

始终选择**测试运行时链路**。找到命令并不代表已经登录或配置正确。

<a id="constraints" />

## 不同工具支持的功能不同

模型选择、会话、技能、对话记录、费用、浏览器工具、Rudder 工具和运行中控制都
取决于具体工具。Codex、Claude Code、OpenCode 和 Pi 支持 Rudder 托管控制
工具；Cursor 和 Gemini 使用自己的连接方式。

界面只应显示所选工具真正支持的功能。切换备用工具会开始另一次尝试，不代表两个
工具能力相同。

<a id="boundaries" />

## 设置运行工具不会自动获得什么

选择运行工具不会自动获得所有组织、Issue、本地文件、凭据、网站或外部服务的
访问权。权限仍然来自当前 Agent、任务、工作区和连接设置。

通用进程和 HTTP 连接属于高级底层能力，不会作为普通设置选项出现。

<a id="examples" />

## 快速选择

- 已经在本机使用 Codex：选择 Codex，测试链路，再完成一项小型 Chat 任务。
- 找到命令但测试提示登录失败：先在 Rudder 外登录对应命令行工具。
- 需要浏览器控制：使用 Desktop 本地可信模式下受支持的本地工具，并开启 Agent
  浏览器访问。
