Workspace boundaries 让 agent 工作可恢复。持久文件要放在未来 run 和 reviewer 找得到的位置。

| 文件或状态 | 正确位置 |
| --- | --- |
| 项目仓库工作 | Project workspace |
| 持久项目输出 | Library 里的项目文件夹 |
| 共享组织参考 | Library |
| 精选 run context | Project Context resources |
| Agent 私有 instructions、memory 和 local state | Agent home |
| Runtime scratch files | `/tmp` 或系统临时目录 |
| 非最终产物的验证截图 | `/tmp` 或系统临时目录 |

## Protected paths

Agents 应该使用 Rudder-managed paths 和 Library references，不要随手创建本地目录。这样能保持 organization boundaries 清楚，也能避免把 private runtime state 和 shared project output 混在一起。

## Backups

Workspace backups 用于 operator recovery 和 inspection。Restore 前先 browse。需要外部副本时 download。不再有恢复价值的 backups 可以删除。
