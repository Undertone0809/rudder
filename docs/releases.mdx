Rudder publishes stable releases for the user-facing install path:

```sh
npx @rudderhq/cli@latest start
```

This changelog tracks stable releases only. Canary builds are published more frequently for validation and Desktop asset testing; use [GitHub Releases](https://github.com/Undertone0809/rudder/releases) when you need prerelease history.

Release entries preserve the product names and historical terminology used when
each version shipped. For current product guidance, use the Concepts, How-to,
and Reference pages in this site. Future release entries should use the current
navigation names and link to the owning page when a term may be ambiguous.

## v0.5.2

Released: 2026-07-24

[GitHub Release](https://github.com/Undertone0809/rudder/releases/tag/v0.5.2)

### New Features

- Added a persistent Messenger workbench that can promote saved views and Side Panel content into the main workspace while preserving live state and context.
- Added secure local web apps in Messenger, including discovery, launch controls, isolated partitions, lifecycle supervision, and recovery after unexpected exits.
- Added response annotations across Chat and Side Chat so users can anchor feedback to exact response ranges and preserve it through queued delivery.
- Added shared Library media playback, richer Browser agent capabilities, and direct Side Panel inspection for spawned subagents.

### Improvements

- Simplified first-run onboarding and restored the bundled Rudder skill-creator workflow with current guidance and evaluation tooling.
- Improved Messenger saved-view organization, grouped keep actions, wide Side Panel resizing, and workbench state continuity across navigation and promotion.
- Improved Browser runtime parity, read-only DOM references, download handling, managed MCP isolation, and runtime credential cleanup.
- Increased default agent-run concurrency and refined Chat activity, run navigation, prompt matching, queue delivery, and draft preflight behavior.

### Bug Fixes

- Fixed duplicate live transcript deltas, queued-message acknowledgement races, response-annotation offset drift, and hidden provider lifecycle details.
- Fixed Desktop shutdown, local-app listener cleanup, runtime recovery, PostgreSQL payload sharing, and canary update behavior.
- Fixed saved-view lifecycle and organization-rule edge cases, hidden-view ghosts, Browser identity persistence, and stale cache eviction.
- Fixed responsive Issue Detail and Library media layouts, global-search status icons, and several release and cross-platform verification regressions.
