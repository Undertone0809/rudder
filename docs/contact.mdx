Rudder is developed in the open. The best contact path depends on what you need.

## Ask a question

Use GitHub Discussions or a focused GitHub issue when you need help understanding installation, local setup, runtime configuration, or the product model.

## Report a bug

Include the smallest useful reproduction:

- Rudder version or commit
- operating system
- install path or development command
- what you expected
- what actually happened
- logs, screenshots, or terminal output when relevant

For security-sensitive reports, do not post secrets, API keys, private logs, or customer data in a public issue.

## Request a feature

Good feature requests describe the agent-work loop you are trying to complete:

- the goal or workflow
- where the current loop breaks
- which human or agent owns the next step
- what output, review, budget, or feedback evidence should be preserved
