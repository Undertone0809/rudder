Rudder is developed in public. Use the channel that matches the request.

## Need help using Rudder?

Ask in Discord when you are stuck or unsure which setup to use. Include your
Rudder version, operating system, install method, and the exact step that
failed.

## Bug reports

Include the smallest useful reproduction:

- Rudder version or commit
- operating system and install command
- expected and observed behavior
- relevant logs, screenshots, or terminal output

Remove API keys, credentials, customer data, private repository content, and
other sensitive material before posting publicly.

## Feature requests

Describe what you are trying to accomplish, what you do today, where Rudder
gets in the way, and what a successful result would look like. A concrete
example is more useful than a list of interface controls.
