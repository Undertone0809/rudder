<a id="start-here" />

让 Agent 像人类队友一样思考、创造、探索，并在真实工作中持续成长。

Rudder 把目标、任务、Agent 的每次执行、评审和反馈串成一个不断改进的工作循环。
人和 Agent 可以在同一个地方分配任务、查看结果、控制花费，并把真正有用的经验
留给下一次工作。

实际使用时，你把任务交给 Agent，看它执行，打开它产出的文件或回答，然后决定
下一步。Rudder 会使用你已有的 Codex、Claude Code、本地命令或 Webhook，而
不是替代它们。

![Rudder 工作空间概览](../images/board-overview.png)

## Rudder 能帮你做什么

- **从 Chat 开始。** 让 Agent 写文案、改代码、做调研或产出其他明确结果，
  不满意就继续聊。
- **用 Issue 管理复杂任务。** 需要负责人、状态、依赖或独立评审时，再把
  工作变成任务单。
- **看清 Agent 做了什么。** 每次运行的结果、过程和可用日志都留在一起。
- **找到真正的产物。** 文件、链接、截图和报告会连接到产生它们的任务。
- **管理重复工作。** 用技能复用做法，用自动化定期运行，并及时发现费用和
  失败。

## 一个简单的例子

假设你想让 Agent 改善产品的上手页面：

1. 你在 Chat 里说明想要什么结果。
2. Rudder 用你选择的运行工具和项目启动 Agent。
3. 你查看进度，打开改好的文件或预览。
4. 你要求继续修改，或者接受结果。
5. 如果任务逐渐变复杂，再创建 Issue，把负责人和评审方式写清楚。

这样过几天再回来看时，你不需要从终端、长对话和一堆来历不明的文件里重新
拼出事情的经过。

## 三步开始

1. 安装并打开 Rudder。
2. 创建组织，也就是团队工作空间，再连接第一个 Agent 运行工具。
3. 让 Agent 完成一件小而真实的事。

```bash
npx @rudderhq/cli@latest start
```
