# Skill Creator Restore Evaluation

This directory compares the restored Rudder `skill-creator` package with the
nine-line placeholder that originally shipped in Rudder.

## Result

- Restored skill: 10/10 assertions passed.
- Clean placeholder baseline: 2/10 assertions passed.
- Eight assertions discriminated between the two configurations; all eight
  favored the restored package.
- Each scenario/configuration has one retained run, so the result is
  directional and does not estimate run-to-run variance.

The first private and organization baseline attempts searched the live
repository and read restored-skill material. Both contaminated attempts were
discarded. Their replacements ran in isolated temporary workspaces containing
only the saved nine-line `old_skill/SKILL.md`; only those clean runs appear in
`benchmark.json`.

## Scenarios

1. Create and explicitly enable a current-agent multi-file skill.
2. Import and additively enable an organization-owned multi-file skill.
3. Improve an existing skill with paired grading, benchmark aggregation,
   analyst review, and a static human review viewer.

## Artifacts

- `old_skill/SKILL.md`: exact nine-line Rudder baseline.
- `evals/evals.json`: prompts and assertions.
- `iteration-1/benchmark.json` and `benchmark.md`: retained run aggregation.
- `iteration-1/analysis.json`: independent post-hoc analyzer notes.
- `iteration-1/eval-*/`: response, transcript, timing, grading, and metadata for
  each retained run.
- `review.html`: static human comparison viewer generated by the restored
  `eval-viewer/generate_review.py`.

The static viewer was checked to contain a prompt and eval id for all six
retained runs.
