# Retired Product Logic Governance

The contract and registry governance process was retired on 2026-09-06.
Its former read-only, separate approval, contract-ID, documentation-depth,
alignment, and deferred-update requirements no longer apply.

Current behavior is established by code and tests. Discuss meaningful design
changes through proposals in `doc/plans/`; do not maintain a second behavioral
specification for each feature. See `doc/engineering/DEVELOPING.md`.
