# Historical Product Contract Reference

The Product Logic Registry workflow was retired on 2026-09-06.
Implementation and tests define current behavior. Use proposals in `doc/plans/`
when a design decision needs discussion; ordinary fixes need no new document.

Files in `domains/`, `workflows/`, `surfaces/`, `registry.yml`, and the old
templates are retained for historical lookup. Their active/guarded metadata and
contract requirements are obsolete. Do not require contract IDs, registry edits,
separate product-doc approval, or alignment packets for development.

`PRODUCT.md` remains product direction and context, not a feature-by-feature
contract. See `doc/engineering/DEVELOPING.md` for the current development workflow.
