## New Features

- Added atomic first-turn Chat creation so new conversations stay draft-local until their opening message is accepted, with consistent behavior across UI, API, and agent tools.
- Added Messenger saved views, project-aware custom groups, promoted Side Chat grouping, and Side Panel tab context menus for organizing active work.
- Added runtime-neutral inline visual artifacts and local-file Side Panel previews from Markdown and structured transcript activity.
- Added failed-run origin cards and the Oreo agent avatar style to make agent identity and recovery context easier to recognize.
- Added a system-app launcher for Library files that Rudder cannot preview directly.

## Improvements

- Refined transcript activity with semantic summaries, stable native Steer placement, coalesced streaming deltas, and bounded chat-title context.
- Improved Side Panel issue scrolling, chat load-error containment, local-file safety boundaries, and project-group paging under production-sized data.
- Reworked public documentation around concrete Rudder workflows and clarified GDPval benchmark sampling, execution, and deployment guidance.
- Consolidated agent, plugin, and skill creation guidance into `rudder-docs`; the legacy bundled `rudder-create-agent`, `rudder-create-plugin`, and `skill-optimizer` skills are no longer shipped.

## Bug Fixes

- Fixed repeated Chat stop, edit, follow-up, and Side Chat lifecycle races so terminal state remains durable and consistent.
- Fixed internal provider and execution events leaking into user-visible transcripts, including empty process placeholders and release events.
- Fixed Automation chat cron validation and transaction integrity, unread group retry loops, saved-view persistence, and duplicate Messenger group keys.
- Fixed local development startup when the Library directory is unavailable and restored expanded issue detail scrolling inside the Chat Side Panel.
