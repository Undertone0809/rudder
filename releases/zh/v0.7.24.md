Rudder 0.7.24 新增本地 Hermes 配置，改善 Chat 恢复和 Desktop 更新，并将新建 Codex Agent 的默认模型设为 GPT-6.2 Sol、推理强度设为 High。

## 新功能

- 新增本地 Hermes Agent 运行时，支持选择 Profile，并在不发送模型提示词的情况下检查配置。
- Desktop 设置新增重启本地运行时的操作。

## 改进

- 新建 Codex Agent 默认使用 GPT-6.2 Sol 和 High 推理强度。模型发现不可用时，仍可选择 GPT-6.2 Sol 和 Astra；已有 Agent 的配置保持不变。
- Codex 和 Hermes Chat 可以在刷新页面或连接中断后恢复已接收消息的回复，不会重复发送消息或覆盖较新的草稿。停止操作会取消当前运行，Run 视图保留工具输入和结果。
- 组织智能现在通过一个默认模型配置处理标题、摘要、分类和 Issue AI 搜索，Codex 的默认模型为 GPT-6 Luna。
- Desktop 更新提供更清晰的重启进度，在中文界面显示中文更新说明，并可在 GitHub API 被限流时发现安装包齐全的版本。
- 移除 Gemini CLI 运行时支持。已有 Gemini Agent 需要切换到受支持的运行时才能再次运行；历史 Run 记录仍可阅读。

## 问题修复

- 在消息确认延迟和路由切换时保持首条 Chat 消息与输入框稳定，移除多余加载提示和界面闪烁。
- 已取消的 Issue 不再通过待处理请求或手动重试唤醒 Agent、重新启动工作。
- 选择工作区备份文件时，文件 URL 现在会保留所选备份，避免打开其他备份中的文件。
- 宽屏下 Messenger 可以同时保留会话列表与 Side Panel，Plugin 分配界面也会显示已保存的 Agent 头像。
- 改善 Windows 内置数据库启动和恢复，并限制后端不可用时 Desktop 退出的等待时间。
