Rudder 0.7.23 makes Projects and Library easier to navigate, keeps local Chat images and saved Issue drafts recoverable, and improves Messenger, Desktop update, Agent Run, workspace file, and startup reliability.

## New

- Added inline local image rendering for Chat Markdown and attachments, with optional previews and a file-link fallback when a local image cannot be loaded.

## Improved

- The primary navigation now groups project work and Library under Projects, while preserving existing Library document URLs and remembered navigation.
- Saved Issue drafts can now be reopened, edited, and saved back to the same draft instead of opening as read-only content.
- Messenger thread sections now use explicit Show more and Collapse controls when needed, hide disclosure controls for short lists, and preserve focus and unread-thread navigation while collapsing.
- Codex local runs no longer treat an in-flight concurrent provider check as an authentication failure.
- Desktop update checks now ignore newer releases until the current platform package and checksum are available.
- Native Agent Run logging now applies backpressure to slow consumers instead of terminating an accepted run when output queues fill.
- Workspace file reads now enforce bounded, path-safe native reads for previews and annotations.
- Startup migration handling now uses a read-only history and plan preflight before mutation, refusing unsafe mismatches.

## Fixed

- Restored primary navigation rail width after the Projects and Library reorganization so labels and active states remain inside the rail across desktop and browser layouts.
- Fixed Chat image-preview cleanup and focus restoration when a preview is closed, while keeping proposal images static instead of opening an interactive preview.
