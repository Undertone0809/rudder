Rudder 0.7.21 keeps new Chat conversations responsive through slow loading and route changes, preserves drafts and attachments when delivery fails, and makes local agent and App workflows more dependable across platforms.

## New

- Added recoverable first-turn Chat drafts. If the first message fails before a conversation is created, Rudder keeps the text and attachments available to retry, even after switching conversations or changing the viewport.

## Improved

- New Chat turns now open the accepted conversation and show streaming progress without waiting for sidebar updates, while keeping a newer conversation selection and draft in place.
- Codex local runs now avoid duplicate provider checks and pick up refreshed authentication and provider configuration, allowing recovery after credentials are updated.
- Windows local App startup now tolerates slower startup checks, reducing false failures while an App is becoming ready.
- App location actions now name the platform's file manager: Finder, File Explorer, or File Manager.
- Chat context menus hide scrollbars until needed, and Issue and Kanban views no longer show redundant end-of-list messages.

## Fixed

- Codex authentication refreshes stay isolated from the shared Codex home while updated credentials are picked up on the next run.
- New project source selection no longer offers the unavailable organization Library option; supported local-file and URL sources remain available.
