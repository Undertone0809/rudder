## New Features

- Added a built-in Desktop browser with secure local profiles, browser settings, Chromium cookie import, local-runtime capability projection, and browser shortcuts for agent workflows.
- Added richer Chat work surfaces with a persistent Work manifest, inline visual artifacts, website previews, forked-chat naming, and improved prompt starters.
- Added Library PDF previews, Markdown editing, default-app launch actions, and side-panel access to organization files.
- Added Automation templates and expanded Desktop startup recovery, diagnostics, and update handling.

## Improvements

- Redesigned Settings, onboarding, Messenger groups, project resource picking, and Side Panel interactions for faster navigation and clearer context.
- Improved agent runtime reliability with supervised server resources, durable terminal recovery, session-lineage diagnostics, coalesced run admission, and bounded run-intelligence payloads.
- Improved organization and workspace migrations, local file preview boundaries, browser error reporting, and release verification across macOS, Windows, and Linux.

## Bug Fixes

- Fixed Chat steering, stopping, scrolling, output finalization, reference rendering, project visibility, and organization-switch recovery regressions.
- Fixed Desktop packaged startup, browser bundle handshakes, MCP stdio attachment, update blockers, and cross-platform shortcut behavior.
- Fixed issue workflow context, Messenger layout, Library controls, website preview isolation, and several CI and documentation deployment regressions.
