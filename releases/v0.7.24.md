Rudder 0.7.24 adds local Hermes setup, improves Chat recovery and Desktop updates, and defaults new Codex Agents to GPT-6.2 Sol with High reasoning.

## New

- Added local Hermes as an Agent runtime, with Profile selection and setup checks that do not send a model prompt.
- Added a local runtime restart action in Desktop settings.

## Improved

- New Codex Agents now default to GPT-6.2 Sol with High reasoning. GPT-6.2 Sol and Astra remain selectable when model discovery is unavailable; existing Agent settings are preserved.
- Codex and Hermes Chat can recover an accepted response after a reload or connection loss without sending the message again or replacing a newer draft. Stop cancels the active run, and Run views retain tool inputs and results.
- Organization intelligence now uses one default model profile for titles, summaries, classification, and Issue AI search, with GPT-6 Luna as the Codex default.
- Desktop updates now show clearer restart progress, display Chinese release notes in the Chinese interface, and can discover complete releases when GitHub's API is rate limited.
- Gemini CLI runtime support has been removed. Existing Gemini Agents must be switched to a supported runtime before running again; historical Run transcripts remain readable.

## Fixed

- Kept the first Chat message and composer stable through delayed acknowledgement and route changes, removing redundant loading messages and visual flicker.
- Cancelled Issues no longer wake Agents or restart work through pending requests and manual retries.
- Selecting a workspace backup file now preserves the selected backup in the file URL.
- Messenger keeps its conversation list visible alongside the Side Panel on wide displays, and Plugin assignments show saved Agent avatars.
- Improved Windows embedded database startup and recovery, and bounded Desktop Quit when the backend is unavailable.
