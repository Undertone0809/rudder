This release makes agent work easier to steer and inspect, while clarifying key Rudder workflows and documentation.

## New

- Added semantic boundaries for agent instructions across supported local runtimes, with coverage for preserving instruction context during execution.
- Added English and Chinese architecture maps to the overview documentation and marked App Builder as beta.

## Improved

- Ask User questions now always offer an `Other` freeform response, including when a caller disables freeform answers, and support the same attachment flow for that response.
- Coordinated Goal Detail tab geometry and improved transcript, workspace copy, and chat workflow presentation.

## Fixed

- Made agent-hire approval checks actor-aware, allowed authorized Issue completion without checkout, and isolated inactive Library side-panel queries.
