This release makes model selection, agent run follow-up, and local workspace recovery more predictable across everyday Rudder workflows.

## Improved

- Reused the same runtime profile controls across Chat and Issue workflows so model and thinking selections are easier to understand and apply.
- Improved agent run transcript loading and live detail updates, including clearer fallback behavior when a run is still settling.
- Improved local workspace backup and restore recovery so interrupted or ambiguous restore states are handled more safely.

## Fixed

- Fixed Chat streaming refresh flicker and improved continuity while opening issue references and run evidence.
