This release makes agent work easier to configure and follow across Chat, Issues, Messenger, and packaged Desktop while adding safer native local runtime support.

## New

- Added optional experimental local voice input to Desktop Chat, including microphone permission handling, local transcription, and cancellation.
- Added native local runtime foundations to packaged Desktop for process hosting, workspace/runtime payloads, and local speech support.

## Improved

- Added model and thinking controls to agent runtime selection in Chat and Issue workflows, with better keyboard and narrow-screen behavior.
- Improved Messenger approval cards with clearer origin context and links back to the related Chat or Issue.
- Improved agent run visibility with clearer loading and failure states, bounded transcript details, and an option to show tool-call failure indicators.

## Fixed

- Fixed Chat streaming refresh flicker and send-feedback timing, and improved continuity when opening issue references, images, and run evidence.
- Fixed several local runtime process, workspace backup, and restore edge cases across packaged Desktop platforms.
